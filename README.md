# mvp-mosaic

Объединим точность алгоритмов с гибкостью творчества: автоматическая конвертация изображения в мозаичную схему и расчёт материалов.

Проект в разработке.

Done:
* Преобразование изображения в мозаичную схему с палитрой, приближенной к цветам оригинала.
* Загрузка пользовательского изображения.
* Пользовательские настройки размеров и палитры.
